# دراسة جاهزية كتالوج Omran Toys للبيع على Amazon مصر

الحالة: دراسة فقط. لم يتم إنشاء حساب أو نشر منتجات أو ربط مخزون.

## الخلاصة

يُنصح ببدء Pilot صغير بمنتجات خفيفة وسريعة الحركة وذات بيانات مورد مكتملة. لا يبدأ الربط قبل حساب هامش كل SKU بعد عمولة الفئة والشحن/التنفيذ والتخزين والمرتجعات. الرسوم تتغير حسب الفئة وطريقة التنفيذ، لذلك تُسحب القيم الحالية من Seller Central وقت اعتماد الـPilot ولا تُثبت داخل الكود.

## بوابة بيانات كل SKU

| الحقل | المصدر المعتمد | شرط الجاهزية |
|---|---|---|
| SKU واسم المنتج | الكتالوج الرئيسي | فريدان ومتطابقان |
| GTIN/EAN/UPC | المورد أو إعفاء Amazon | لا يُخمن |
| العلامة التجارية | العبوة/المورد والحقوق | مستندات مطابقة |
| الصور | وسائط المنتج الحقيقية | صورة رئيسية وصور إضافية بلا خلط |
| الأبعاد والوزن | المورد أو قياس معتمد | المنتج والعبوة منفصلان |
| العمر والسلامة | المورد | نص موثق فقط |
| المخزون والسعر | التشغيل التجاري | مصدر مستقل ومراجعة قبل النشر |

## Mapping مقترح

- `product_id` → مرجع Omran الداخلي، و`sku` → Seller SKU.
- `gallery_images` → MAIN ثم الصور الإضافية حسب ترتيبها المعتمد.
- حقول المنتج والعبوة والوزن → سم/كجم بعد التحقق، مع تحويل الوحدات في ملف تصدير مشتق فقط.
- `material`, `pieces_count`, `power_source`, `box_contents` → سمات الفئة والوصف النقطي عند قبولها.
- لا يُرسل كتالوج POP UP ضمن ملف لعب الأطفال؛ له Mapping وقناة مستقلة إذا اعتمد لاحقًا.

## التشغيل والمخاطر

- قارن FBM وFBA لكل SKU؛ FBA يضيف رسوم تنفيذ وتخزين تعتمد على الحجم والوزن، وقد يضيف تكلفة للمخزون بطيء الحركة.
- احتفظ بمخزون أمان ولا تربط المخزون الفعلي آليًا في المرحلة الأولى.
- راجع حقوق العلامة وصور العبوة؛ Amazon قد يطلب GTIN أو إعفاء وصورًا حقيقية تثبت العلامة.
- ابدأ بـ 10–20 SKU، وراجع هامش المساهمة والمرتجعات وأخطاء الإدراج أسبوعيًا قبل التوسع.
