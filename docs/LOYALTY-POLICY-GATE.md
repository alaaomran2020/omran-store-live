# بوابة اعتماد نظام نقاط عمران تويز

الحالة: البنية التقنية جاهزة، والتفعيل المالي متوقف عمدًا.

## ما تم تجهيزه

- سجل حساب عميل منفصل عن سجل الحركات.
- أنواع حركات للمشتريات، المراجعات، صور المراجعات، الاستبدال، تسوية المرتجعات والتعديلات.
- اشتراط التحقق، ومنع تكرار المرجع، وعدم اشتراط تقييم إيجابي.
- حقول للصلاحية والمبلغ بالجنيه وحالة الحركة، بدون Backend أو خدمة مدفوعة جديدة.

## قرارات مطلوبة قبل التفعيل

1. معدل اكتساب النقاط لكل جنيه.
2. قيمة النقطة عند الاستبدال والحد الأدنى.
3. الحد الأقصى للخصم في الطلب الواحد.
4. مدة الصلاحية وقواعد الإخطار.
5. قيمة مكافأة المراجعة والصورة، ومعيار إثبات الشراء.
6. إجراء الفرع للتحقق من الهوية والاستبدال والمرتجعات.

لا تُسجل أرصدة حقيقية ولا تُعرض وعود خصم للعملاء قبل اعتماد البنود السابقة واختبار دورة شراء ومرتجع كاملة.
